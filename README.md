# Dairy CIP simulation framework

A research prototype for modeling and evaluating alkaline cleaning-in-place (CIP) recipes for a single dairy line. It combines a MATLAB/Simulink process model with Python analysis, surrogate modeling, optimization, and uncertainty screening.

## Data and limitations

Most data and results are synthetic and generated by simulation. Published laboratory cleaning curves are included for kinetic benchmarking. The model is not calibrated to an operating plant, and its outputs are not operational recommendations. Industrial use requires calibration, independent verification, and food-safety validation.

See [the methodology note](docs/methodology_note.md) and [the limitations note](docs/limitations_note.md) for further context.

## Quick start

Install the Python dependencies:

```bash
pip install -r requirements.txt
```

From MATLAB at the repository root, build the model if needed and run the main pipeline:

```matlab
addpath('src')
run('src/build_model.m')
run('src/run_full_pipeline.m')
```

The model uses Simulink, Statistics and Machine Learning Toolbox, and Global Optimization Toolbox. Python dependencies are listed in `requirements.txt`.

## Repository contents

- `src/` - model construction, simulation, analysis, and validation code.
- `model/` - Simulink models.
- `data/` - input and simulation datasets.
- `results/` - generated analysis outputs.
- `docs/` - methodology, limitations, and release notes.

The project is a research artifact, not a validated control system. See [CITATION.cff](CITATION.cff) for citation information.
